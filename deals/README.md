# HOWTRAVLE 便宜票雷達（新版）

只呈現「台灣出發 → 日本・韓國・泰國・越南」的**預估低價機票**和**精選便宜酒店**。
不提供搜尋。頁面上每一個連結都是 Trip.com 聯盟連結（Allianceid `7106961`／SID `261258404`）。

舊版 `cheap-flights/` 保留不動。

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 網頁本體 |
| `worker.js` | 每天自動抓低價機票的程式，部署在 Cloudflare |
| `picks.json` | 「Adam 今日精選」：HOWTRAVLE 每日 Top 2，已在 Trip.com 核對過價格（空的就自動挑，見下面「今天最划算」） |
| `hotels.json` | 精選酒店（評分 8.0 以上才會顯示） |
| `check-links.mjs` | 上線前檢查：確認每個連結都帶聯盟編號 |
| `check-layout.mjs` | 上線前檢查：5 種螢幕寬度下量測照片、標誌、卡片有沒有沒對齊或跑版 |
| `check-worker.mjs` | 抓價程式檢查：每段查詢次數、資料格式、累積資料庫的累積與清除規則 |

## 機票資料怎麼來

- 價格來自 Travelpayouts 的低價快取，是**預估最低價**，網頁上有標明。
- 主要來源：Cloudflare Worker `howtravle-deals`（https://howtravle-deals.a8225012.workers.dev/，程式碼就是 `worker.js`），
  每 3 小時更新一次，分成幾段（Cloudflare 免費方案每段最多對外查 50 次）：
  - `/`：依出發地 × 月份，抓日韓泰越＋大陸港所有低價
  - `/?part=fsc`：47 條航線指定抓，只留傳統航空
  - `/?part=m0`～`m3`：44 條熱門航線 × 每個月（m0＝本月），每條每月留最便宜 60 組日期，讓選擇更多。
    網頁先顯示前兩段，這四段到了再自動補進去。熱門航線清單在 `worker.js` 的 `HOT_ROUTES`（總數要在 48 以下）
  - `/?part=g0`～`g3`：同一批熱門航線改用「每天最低價」（grouped_prices）查詢，補上 m 段沒有的日期
  - `/?part=all`：累積資料庫（選用，見下一節）。累積到 300 筆以上，網頁就只讀這一個，不再分段抓
  - `/?part=probe&o=KHH&d=SEL`：測試頁，比較不同市場／查詢方式的資料量
- 備援：舊版 Worker `cold-union-5668`。舊版網頁 `cheap-flights/` 還在用它，不要刪。
- 改了 `worker.js` 之後，要把新內容貼回 Cloudflare 的 `howtravle-deals` 再按 Deploy 才會生效。

## 累積資料庫（選用，設定後航線會越來越多）

免費資料來源只會給「最近有人搜尋過」的票，過一陣子就消失。設定 Cloudflare 的 KV（免費的小資料庫）和排程後，
抓價程式每 10 分鐘輪流抓一段（共 14 段，含第二批 46 條二線城市航線，約 140 分鐘一輪），把看到的票存起來：同一組日期＋航空用最新價格，**超過 3 天沒再看到或已出發的票自動刪除**，
每條航線每個月最多留最便宜的 60 筆。

設定步驟（只要做一次）：
1. Cloudflare 左邊選單「儲存空間和資料庫」→「KV」→「建立」，名稱填 `howtravle-deals`
2. 回到 Workers 的 `howtravle-deals` →「設定」→「繫結」→「新增」→ 選「KV 命名空間」，
   變數名稱填 `DEALS`，命名空間選剛剛建立的 → 部署
3. 同一頁「觸發事件」→「Cron 觸發器」→「新增」→ 選每 10 分鐘（Cron 寫法：`*/10 * * * *`）
4. 打開 `https://howtravle-deals.a8225012.workers.dev/?part=all`，看到 `count` 大於 0 就成功了；
   跑完一輪（約 140 分鐘）後資料會越來越多

免費額度：KV 每天 1000 次寫入，每 10 分鐘一次排程約用 288 次，夠用；粉絲讀取有 10 分鐘的邊緣快取，KV 讀取次數很少。
資料庫存成精簡格式（`cols`＋`data`），最多 4000 筆（超過只留最便宜的），用來控制免費方案的 CPU 時間
（實測 8000 筆時排程一次約 18 ms、粉絲讀取約 2 ms）。如果 Cloudflare 的 Worker 記錄出現「Exceeded CPU」，
把 `POOL_MAX_ROWS` 調小，或升級 Workers 付費方案（每月 5 美元）。

## 頁面順序（手機由上到下）

大圖輪播 → 依地區探索 → 我收藏的航線 → 今天最划算 → 連假倒數 → 篩選＋機票卡 → 熱門航線 → 說走就走 → 便宜票雷達 → 怎麼用。
機票卡是精簡版：照片較矮、去程／回程並排、價格和「去 Trip.com 訂」同一排；手機一次 6 張（平板 8、電腦 9），按「再看」載入更多。

## 今天最划算（自動精選）

`picks.json` 有手動精選時顯示「Adam 今日精選」（只在便宜機票分頁）。沒有的話，網頁每天自動挑 2 張：
比平常便宜最多的優先，其次直飛、週末或連假出發，最後看價格；同一個城市只挑一次，盡量不跟大圖第一張重複。
傳統航空分頁也會自動挑（只從傳統航空裡挑）。

## 熱門航線（沒有預估價的航線）

資料來源只記錄有人在 Aviasales 搜尋過的票，台灣出發的航線常常沒有資料（例如台中→首爾）。
`index.html` 的 `POPULAR_ROUTES` 列出熱門航線，目前畫面上沒有價格的就放在「熱門航線」區，
點了開 Trip.com 搜尋頁，粉絲可以在 Trip.com 改日期。建議日期寫在區塊上方：
- 一般：所選月份第一個週五出發、週一回來（至少一週後）
- 選「週末」：週五出發、週日回來
- 選「連假」：那個月的連假第一天出發、最後一天回來

傳統航空分頁也有熱門航線（提示粉絲在 Trip.com 篩選航空公司）。連結一樣經過 `affiliate()`。

## 沒有價格時

- 地區磚塊、月份按鈕沒有預估價時寫「查即時價」，有價格的地區排在前面
- 篩選到沒票：顯示「這個條件目前沒有預估低價」＋「看全部最便宜的票」按鈕，熱門航線會放 8 個
- 完全抓不到資料：顯示「今天的低價票還在整理中」＋直接去 Trip.com，熱門航線照常顯示
- 這個月剩不到 7 天、又沒有票時，月份直接從下個月開始；已經過去的連假不再提示

## 互動功能（讓粉絲多停留）

- **價格日曆**：卡片上「看全部 N 組日期」→ 彈出面板，月曆上每天的最低價依便宜／普通／偏貴上色（日期對齊星期，檢查程式會驗證），
  點日期會標出下面對應的選項；也顯示時差、飛行時間、當地貨幣。每個選項都是聯盟連結。
- **比平常便宜 X%**：同一條航線（同來回／單程）至少 8 組日期時，跟中位數比，便宜 15% 以上才顯示綠色標籤；最多顯示「60%+」，避免誇大。
- **幫我選！**：從目前最便宜的 15 個城市隨機抽一個，有拉霸動畫（系統設定減少動態時直接顯示結果）。
- **連假倒數**：顯示下一個連假還有幾天、連假出發最低價，點了直接切到連假篩選。
- **預算**：篩選面板多一排預算（來回：不限／5 千／8 千／1 萬 2；單程：不限／3 千／5 千／8 千）。
- **分享**：卡片和價格日曆都有「分享」，手機用系統分享選單，電腦複製連結；IG／LINE 內建瀏覽器不能自動複製時，
  會跳出一個可以長按複製的連結框。分享的網址是 `…/deals/?route=TPE-OSA&src=share`：打開會直接跳出那條航線的價格日曆，
  後台 `trip_sub1` 會是 `howtravle_share`。在傳統航空分頁或單程分享時會多帶 `&m=fsc`、`&t=ow`，朋友打開是同一種票。
- **飛行時間**：資料有提供時，去程旁邊顯示「約 2 小時 30 分」。
- **酒店**：酒店分頁列出 14 個熱門城市（東京、大阪、福岡、沖繩、札幌、首爾、釜山、濟州、曼谷、清邁、峴港、胡志明市、香港、上海），
  上面可選入住日期（最近的週末、下個週末、下一個連假），點城市開 Trip.com 該城市的酒店搜尋頁（2 位成人、1 間房）；城市代碼在 `HOTEL_CITY`。
  - 每個城市有「平價住宿每晚約 NT$○–○」參考價，由便宜到貴排。**這是人工估的價位**（平價酒店雙人房、非旺季），在 `HOTEL_REF`，
    建議每季到 Trip.com 看各城市「價格由低到高」前幾間，再更新這裡。
  - 城市卡上有該城市最便宜的來回機票（點了開價格日曆）；沒有預估價的城市改成「查○○出發機票」，用同一組日期開 Trip.com 機票搜尋。
  - 價格日曆下方也有「順便看○○的酒店」，入住／退房日期跟最便宜那張機票一樣，並附上參考價。酒店佣金比機票高，這是重點導流。
- **收藏航線**：卡片上的愛心，收藏後最上面出現「我收藏的航線」，每次打開顯示那條航線現在最便宜的價格。
  只存在粉絲自己的瀏覽器（localStorage），換手機或清除資料就不見。
- **說走就走**：近 3 週週末出發（週四～六出發、週日或週一回、1～4 晚）最便宜的 10 個城市，橫向滑動小卡，點了直接到 Trip.com。
- **便宜票雷達**：以台灣為中心的雷達圖，城市依真實方位與距離（圈圈是 500／1000／2000／3000 公里）擺放，
  越便宜點越大越綠，最便宜的 3 個會閃；點一下打開價格日曆。最多畫最便宜的 35 個城市，標籤從便宜的開始放、
  不會蓋住任何點。旁邊（手機在下面）有「最便宜的城市」排行榜，點了一樣開價格日曆。城市座標在 `index.html` 的 `COORDS`，新增城市時要一起補。

## 讓粉絲停留更久的小設計

- **快速入口**（大圖下面一排）：比平常便宜 N 條、我的收藏、說走就走、連假倒數、雷達、幫我選，只放現在有內容的
- **比平常便宜**：篩選列多一個選項，只看比同航線平常便宜 15% 以上的票（沒有特價時不顯示）
- **收藏降價提醒**：記住粉絲上次看到的最低價（存在粉絲自己的瀏覽器），再打開時顯示「比你上次看便宜 NT$○」並跳提示；
  來回／單程、兩個分頁分開記；等細抓資料到齊（最多 10 秒）才比較，避免假的降價
- **第一次來的說明條**：說明價格是預估、點了到 Trip.com；按 × 後不再出現
- **點卡片的去回程日期**直接打開價格日曆；滑到清單下面時右下角有「篩選」按鈕回到篩選
- **分享網站**：頁尾前「揪旅伴一起看」，網址帶 `src=share_site`，後台看得到從這裡分享出去的訂單

## 設計

參考 Airbnb（照片為主、文字在照片下面、整張卡片可點）、Apple（白底、分段切換的分頁、大字與留白）、
Google Flights（沒有外框的篩選膠囊、價格用顏色分）。
- 顏色、圓角、陰影都寫在 `index.html` 最上面 `:root` 的變數，要改整站風格改那裡
- 機票卡：點照片、城市、價格 → 去 Trip.com；點「日期那一行」或「N 組日期 ›」→ 價格日曆；點愛心 → 收藏
- 分享預覽圖 `og.png`（1200×630）、手機主畫面圖示 `icon-180/192/512.png`、`manifest.webmanifest`。
  從主畫面打開的網址會帶 `?src=home_screen`，後台看得到從主畫面來的訂單
- **大圖登機證**：城市名下方一張毛玻璃登機證（機場代碼、天數／直飛、去回程日期、價格），兩側半圓缺口用 CSS mask 做；
  不支援 mask 的瀏覽器會顯示成一般圓角卡片。酒店分頁是同樣造型的「房卡」（地區依 `HOTEL_CITY` 自動算）
- **想去哪？**：一排圓形照片（像 IG 限時動態），最便宜的地區外圈是漸層色
- **月份按鈕**：左邊的價格長條越高越便宜，最便宜的月份是綠色
- **價格日曆**：上方有小登機證（代碼、飛行時間、最低價）
- **字型**：英文與數字 Plus Jakarta Sans、中文 Noto Sans TC（Google Fonts）；價格是「NT$」小字＋數字大字
- **區塊標題**上方的金色英文小字寫在 `data-eb`（例如 `data-eb="DEALS"`），讀屏不會讀
- 小字顏色對比至少 4.5:1（檢查程式會量）

## 動畫

載入中飛機飛過雲層；大圖有虛線航線與小飛機、文字依序浮上來、價格第一次出現時跳數字；卡片捲到才浮上來；
最低價火焰跳動、少數標籤閃光（只閃 6 次）；最低價卡片金色外框；收藏愛心彈跳；幫我選抽中灑彩帶；
價格日曆打開時航線畫出來、飛機飛到目的地，日期一格一格出現；雷達的點依便宜順序彈出；連假倒數翻牌；
酒店大圖星星閃。
- 手機設定「減少動態」時全部關掉（iPhone：設定→輔助使用→動作；Android：設定→協助工具→移除動畫）
- 大圖捲出畫面時暫停，發光用透明度做，盡量省電
- 檢查程式：版面在動畫關閉時量；另外有一段「動畫開著」的檢查，確保沒有東西一直隱形、動畫結束後版面一樣對齊

## 分辨哪篇貼文帶來訂單

分享網址後面加 `?src=名稱`，例如：

```
…/deals/?src=ig_day9
```

Trip.com 後台的 `trip_sub1` 就會顯示 `howtravle_ig_day9`。只能用英文、數字、`_`、`-`。

## 每日精選格式（picks.json）

```json
{
  "updated_at": "2026-10-24T09:00:00+08:00",
  "items": [
    { "origin": "TPE", "destination": "OSA", "departDate": "2026-11-13", "returnDate": "2026-11-17",
      "price": 5980, "direct": true, "checkedAt": "2026-10-24T09:00:00+08:00", "note": "大阪直飛不到六千" }
  ]
}
```

已出發的會自動隱藏。

## 酒店格式（hotels.json）

```json
{
  "updated_at": "2026-10-24T09:00:00+08:00",
  "items": [
    { "city": "東京", "country": "JP", "name": "酒店名稱", "area": "淺草站步行 3 分鐘", "rating": 8.6,
      "pricePerNight": 2450, "checkin": "2026-11-03", "checkout": "2026-11-07",
      "url": "從 Trip.com 複製的酒店網址" }
  ]
}
```

- `country`：`JP` 日本、`KR` 韓國、`TH` 泰國、`VN` 越南、`CN` 中國大陸、`HK` 香港
- `image`（選填）：酒店照片網址（https 開頭）；不填就用該城市的地標照片
- `url` 必須是 trip.com 的網址，聯盟參數會自動補上；其他網站的網址會被擋掉不顯示。

## 連假日期

在 `index.html` 的 `HOLIDAYS`，依人事行政總處公告填寫，目前填到 2027 年清明連假。每年公告新日曆後要補上。

## 照片與航空公司標誌

- **城市照片**：在 `index.html` 的 `LANDMARKS`，每個城市一個代表地標（例如東京＝東京鐵塔），
  照片在粉絲的瀏覽器裡從英文維基百科即時抓取（Wikimedia Commons，各作者依原授權），抓過的會記 7 天。
  想換照片：把該城市的英文維基條目名稱換掉即可。抓不到照片時會顯示該國的漸層底，版面不會壞。
- **地區磚塊照片**：`COUNTRY_PHOTO`。
- **航空公司標誌**：Travelpayouts 的 `pics.avs.io`，失敗改用 `img.wway.io`，都失敗就顯示航空代碼。
- **大圖輪播**：自動挑目前分頁最便宜的 5 個城市（`CONFIG.heroSlides`），每 5.5 秒換一張。

## 上線前檢查

```
node deals/check-links.mjs
node deals/check-layout.mjs
node deals/check-worker.mjs
```

三個都看到 ✅ 才上線。檢查程式用模擬價格與模擬照片測試，不會出現在正式網頁上。

`check-layout.mjs` 會用跟正式網站一樣的字型量寬度（數字的寬度會影響會不會擠）。字型檔放在 repo 根目錄的 `.work/fonts`
（`.gitignore` 已排除 `.work/`，不會進 git），第一次用時下載：

```
mkdir -p .work/fonts && cd .work/fonts
npm pack @fontsource/plus-jakarta-sans@5 @fontsource/noto-sans-tc@5
mkdir pj nt && tar -xzf fontsource-plus-jakarta-sans-*.tgz -C pj && tar -xzf fontsource-noto-sans-tc-*.tgz -C nt && mv nt/package noto
```

沒下載也能跑，只是會提醒「用系統字型量」。也可以用環境變數 `HOWTRAVLE_FONTS` 指定別的資料夾，裡面要有 `pj/` 和 `noto/`；
每個資料夾可以是 `pj/package/400.css`（npm pack 解開的樣子）或直接 `pj/400.css`。
