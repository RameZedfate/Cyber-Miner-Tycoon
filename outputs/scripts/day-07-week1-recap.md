# Day 7／100 — 「第一週的實話」

**支柱：** 成果數字 ｜ **形式：** **圖文輪播（模板 A 米色底）** ｜ **不出鏡**
**這支要讓觀眾記住：** 他會講哪些沒用。所以他講有用的時候，可以信。

> 💡 **這天故意不做 Reels。** 連錄六天你會累，回顧型內容用輪播製作快很多，
> 剛好讓你在第一週結束時喘一口氣 —— 這是撐到 100 天的設計，不是偷懶。

---

## 輪播內容（7 頁）

### 封面（模板 A：米色底 `#F2EBE0`）

```
第一週結束。
講點實話。

└ 哪些真的有用，哪些是我自己在感動
```
> 「實話」兩字用紅色 `#C8102E`

---

### P2 — 最有用的，不是我以為的那個

```
我本來以為最有用的是「自動寫文案」。

不是。

最有用的是第一天那份調性檔。

因為後面每一篇都靠它。
我不用再重講一次我是誰。
```

---

### P3 — 真正省下的時間在哪

```
省的不是打字時間。

是校稿時間。

以前一篇要改三遍才不像機器人講話。
現在第一版就是我的語氣。
```

---

### P4 — 最沒用的

```
兩個工具到現在打不開。

做圖那個不能用，
所以我做圖還是自己來。

這件事沒有變輕鬆。
```

---

### P5 — 我第三天就想偷懶了

```
每天現做真的會累。

第三天我就開始想「今天跳過好了」。

後來改成一次錄一週，
週間只要發文跟回留言。

會斷更的都是每天現做的人。
```

---

### P6 — 一週的數字

```
7 天
7 則貼文
2 個工具沒弄好
1 個發現：

工具不會讓你變勤勞，
只會讓勤勞的人省力。
```
> 這頁的數字用大字，「工具不會讓你變勤勞」那句用紅字

---

### P7 — 預告 + CTA

```
下週我要換個方向。

不講怎麼做內容了，
講我上班真正最花時間的那件事。

那件事跟 90% 的上班族都有關。
```

```
我本來以為最有用的會是「自動寫文案」。
結果不是。

以前一篇要改三遍才不像機器人講話，現在第一版就是我的語氣。

至於沒用的：
```
