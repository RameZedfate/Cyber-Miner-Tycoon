# Day 4／100 — 「同一篇文複製貼到三個平台，你有沒有發現都沒人理」

**支柱：** 觀念釐清 ｜ **形式：** Reels ｜ **長度：** 42 秒 ｜ **不出鏡**
**這支要讓觀眾記住：** 不是內容不好，是你把「同一種說法」搬到了「不同種讀法」的地方。

---

## 逐字稿

| 時間 | 口白 | 畫面 | 字卡 |
|---|---|---|---|
| **0-3s** | 「同一篇文，你是不是也複製貼到 IG、Threads、限動？」 | 三個平台並排，同一段文字 | **一模一樣** |
| **3-8s** | 「我以前也這樣。然後 Threads 那邊永遠沒人理我。」 | Threads 那格的互動數字（可打碼） | — |
| **8-14s** | 「後來我才懂——不是內容不好，是那不是同一種看法的方式。」 | 三格分開 | **不是同一種看法的方式** |
| **14-22s** | 「IG 的人願意慢慢看完。Threads 的人只想知道你的立場。」 | 左：IG 長文；右：Threads 短句 | — |
| **22-34s** | 「所以現在同一件事，我寫三個版本。Threads 那版我把教學全砍掉，只留觀點——反而有人回。」 | 三欄並排對照，同主題三種寫法 | **同一件事，三種寫法** |
| **34-42s** | 「複製貼上最省事，但那是省你的事，不是省觀眾的事。Day 4／100。」 | 定格 | **Day 4／100** |

## 拍攝清單

- [ ] 三個平台貼同一段文字的畫面（手機錄）—— 8 秒。**互動數字記得打碼或裁掉**
- [ ] 三欄並排的產出畫面 —— 12 秒
- [ ] Threads 版特寫（看得出來明顯比較短）—— 6 秒
- [ ] 錄影前：字級放大 2.5 倍

## 剪輯註記

- 22-34 秒的**三欄並排是這支的靈魂**，一定要三個版本同時在畫面上，讓長度差異一眼可見
- 34 秒那句「省你的事，不是省觀眾的事」是金句，字卡打出來，停 1.5 秒
- 這支是觀念類，也可以改做輪播（模板 A 米色底），如果那週太忙就換成輪播

## IG 貼文文案

```
同一篇文，複製貼到 IG、Threads、限動。

我以前也這樣。
然後 Threads 那邊永遠沒人理我。

後來才懂：不是內容不好。

是那不是同一種「看」的方式。

IG 的人願意慢慢看完，你可以鋪陳。
Threads 的人只想知道你的立場，鋪陳到第三句他已經滑走了。

同樣一件事，我現在寫三個版本。
Threads 那版我把教學全部砍掉，只留一個觀點。
反而開始有人回我。

複製貼上最省事。
但那是省你的事，不是省觀眾的事。

Day 4／100
```

## Threads 版（這支的 Threads 版特別重要，本身就是示範）

```
把 IG 的文複製到 Threads，然後怪 Threads 沒流量。

不是平台的問題。

IG 的人願意慢慢看完。
Threads 的人只想知道你的立場。

我現在 Threads 版都把教學砍光，只留一句觀點。
反而有人回。

複製貼上是省你的事，不是省觀眾的事。

Day 4／100
```

## ⚠️ 錄之前確認

- 秀舊貼文的互動數字時，**如果數字很難看就打碼或只秀輪廓**。誠實不等於要自曝其短到影響觀感。
- 三欄對照的內容要是**同一個主題**，不然對照不成立。
