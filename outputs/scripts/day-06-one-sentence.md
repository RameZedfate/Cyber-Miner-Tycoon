# Day 6／100 — 「我只打了一句話」

**支柱：** 痛點實測 ｜ **形式：** Reels ｜ **長度：** 42 秒 ｜ **不出鏡**
**這支要讓觀眾記住：** 不是「AI 會聊天」，是「AI 會自己動手做完一整件事」。

> 🔑 **這支的畫面衝擊力是第一週最強的。** 觀眾看到檔案自己長出來、說明書自己被寫出來，
> 比任何解釋都有用。素材就是你 7/27 那場對話，直接錄螢幕。

## 拍攝清單

- [ ] 空輸入框 → 打字 → 送出 —— 7 秒。**打字用正常速度**，這是唯一「人在操作」的畫面，要真實
- [ ] 抓取／檢查過程 —— 錄整段，剪到 15 秒
- [ ] 檔案樹展開的畫面 —— 8 秒，**這是最有衝擊力的一幕，滑慢一點**
- [ ] README 內容往下滑 —— 5 秒
- [ ] commit 紀錄 —— 4 秒
- [ ] 錄影前：字級放大 2.5 倍（terminal 畫面尤其重要）

## 剪輯註記

- 0-7 秒**不要加速**，讓觀眾看清楚「真的只有一句話」
- 14-22 秒「它自己檢查安全」這段是最多人沒想到的點，字卡「**這步我沒叫它做**」要停滿 2 秒
- 22-32 秒檔案樹展開時，可以配一個輕的音效節拍，強化「東西一直長出來」的感覺
- 全片節奏由慢到快再收，最後 commit 那格定住

## IG 貼文文案

```
我打了一句話。

「幫我把這套工具裝進來，讓你之後可以用。」

就這樣。

然後它：

1. 去把整包東西抓下來
2. 自己看過一遍，確認裡面沒有奇怪的指令才裝
   （這步我沒叫它做）
3. 挑了該放的位置裝好
4. 寫了一份說明書，告訴我哪些能用、哪些不能用、為什麼
5. 自己存檔上傳

全程我只打了那一句話。

最讓我意外的是第 2 步。
我沒要求它檢查安全，它自己做了。

我一直以為 AI 是「你問，它答」。
原來它可以「你說一句，它做完一整件事」。

Day 6／100

明天：第一週的實話。哪些真的有用，哪些是我自己在感動。
```
