## 中文字卡（assets/card1~7.png，1280×720 透明底）

投影想加字卡時，用剪映把 `cardN.png` 疊到第 N 段上（約第 1.2 秒進、13.8 秒出；第 7 段置中大字收尾）。
字卡由 `assets/make_cards.py` 產生（Noto Sans TC + 金色描邊 + 黑色光暈）。

## 本機進階重製（可選）

想要「交叉淡化轉場＋字卡燒錄＋旁白自動壓低配樂 (ducking)」的進階版，可在本機執行 `assets/assemble.py`：

1. 從 Higgsfield 網站（My Creations）下載 7 段影片存成 `scene1.mp4`～`scene7.mp4`、7 段旁白存成 `vo1.mp3`～`vo7.mp3`
2. 下載字型：`https://fonts.google.com/noto/specimen/Noto+Sans+TC`（存成 `notosanstc.ttf`）
3. `pip install pillow imageio-ffmpeg` 後執行 `python make_cards.py && python assemble.py`
4. 輸出 `worldcup_kickoff_final.mp4`（含 0.6 秒交叉淡化、頭尾淡入淡出、響度正規化 -14 LUFS）

## 想再鋪一條連續配樂？

伺服器拼接版的磅礡感來自每段內建的管弦樂音效。若想要「一條完整連貫的配樂」，最快做法：
剪映 → 音訊 → 音樂庫搜「epic」或「史詩」→ 拖到軌道 → 音量調 -15dB 左右墊在底下即可。
