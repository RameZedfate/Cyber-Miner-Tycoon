# 保單保費總表（範本）

一份**單檔 HTML** 的家庭／客戶保費總表。點兩下就能用瀏覽器打開，不用網路、不用安裝、不用 Excel。

- 檔案：`premium-table-template.html`
- 裡面是**假資料範例**（王大明一家），照著格式改成實際保單即可。

## 它會自動算什麼

| 區塊 | 內容 |
| --- | --- |
| 頁首 | 全戶年繳總保費、平均每月、被保險人數、保單張數、外幣保單金額與佔比 |
| 每位被保險人 | 明細表（保險公司・商品／要保人／年繳保費／佔本人比重）＋ 年繳小計 |
| 誰在繳保費 | 依**要保人**彙總 —— 誰名下扛了多少保費、替誰繳幾張 |
| 保費分佈 | 依**保險公司**彙總，由高到低 |

外幣保單表上先寫原幣（US$），下面那行 `≈` 才是換算後台幣。頁首可以直接改匯率，全表即時重算。

## 怎麼改資料

用記事本（或 VS Code）打開 HTML，拉到最下面找到：

```
/* ▼▼▼ 保 費 資 料 ▼▼▼ */
```

每一張保單就是一行：

```js
{ 公司:"Ａ人壽", 商品:"終身醫療", 保費:24000, 幣別:"TWD", 要保人:"王大明", 生效日:"", 類型:"醫療" }
```

| 欄位 | 說明 |
| --- | --- |
| `公司` / `商品` | 保險公司、商品名稱 |
| `保費` | 年繳金額，**只填數字**，不要逗號 |
| `幣別` | `"TWD"` 或 `"USD"` |
| `要保人` | 誰繳錢／誰能動這張保單。填被保險人自己的名字就會顯示「本人」 |
| `生效日` | 民國格式如 `"111/08/01"`，會自動附上西元；不填就留 `""` |
| `類型` | 失能／醫療／重大傷病…；不確定就留 `""`，不會顯示 |

`你提供的總額` 是選填的對帳用欄位：填了會在頁尾跟計算結果核對，填 `0` 就只顯示計算值。

改完存檔 →  瀏覽器按 F5 重新整理。要交給客戶就按「🖨️ 列印 / 存成 PDF」。
