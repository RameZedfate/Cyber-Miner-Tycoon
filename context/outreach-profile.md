### 被問「你做什麼工作」的三種回答

- **最輕**（第 1-2 階、關係還淺、對方隨口問）— ⏳ 待確認

- **中**（第 3 階、對方明顯有興趣）— ⏳ 待確認

## 二、語氣校準 ⭐ 這一區最重要

### 招牌句型：**拋一個「可能會錯」的觀察**

從三則真實限動回覆歸納出來的，這是 Adam 最強的武器，**所有草稿優先用這個句型**。

**做法：** 看著限動裡的**具體細節**，講一個帶點判斷、可能猜錯的觀察。
**不要用問句。**

| 真實範例（他自己傳的） | 在做什麼工 |
|---|---|
| 「衣服好像沖繩買的衣服！」 | 認出衣服風格 → 對方忍不住澄清「不是」 |
| 「中間C位很顯眼哈哈」 | 認出他在合照裡的位置 → 對方接了一句人生哲學 |
| 「看起來只有開合跳三十下最容易達成🤣」 | 真的看了挑戰清單的內容 → 對方認同並自嘲 |

**為什麼這比問句好用：**

- 問句有壓力（要回答、要負責任），觀察沒有
- 但觀察裡有個「判斷」，對方會**忍不住糾正或認同** —— 回覆動機來自這裡
- 猜錯反而更好：對方澄清的那句話，資訊量通常比正確答案高
  （例：猜錯衣服來源 → 對方講出「男友穿不下的」→ 話題直接進到生活）

> 🔑 **三則的共通點：他每一則都證明「我真的看了你的限動」。**
> 這正是限動回覆的全部價值所在。也是為什麼這件事不能自動化。

### 硬規則（從真實訊息歸納，草稿必須遵守）

| 規則 | 證據 |
|---|---|
| **一行。10-20 字。** | 三則全部一行，沒有例外 |
| **不打招呼。** 沒有「嗨」「哈囉」「好久不見」 | 三則都直接進內容 |
| **不用問號。** 用陳述句 + 微吐槽 | 三則零問號 |
| **表情符號一則最多一個，放句尾** | 只用 🤣 😆，不用愛心、不用波浪號～ |
| **「哈哈」當句尾軟化** | 「中間C位很顯眼哈哈」 |
| **可以用一個驚嘆號** | 「沖繩買的衣服！」（跟貼文標題規則不同，私訊可以） |
| **玩笑要輕，不刻薄** | 「戀愛的男生身材都會變化😆」 |

### 第二則怎麼接（他做對過一次）

對方回了之後，**接住並延伸**，不要只按表情：

> 他：「衣服好像沖繩買的衣服！」
> 對方：（澄清 + 帶出男友話題）
> 他：「戀愛的男生身材都會變化😆」 ← **這句是關鍵**
> 對方：（開始講自己的事）← 進到第 2 階了

第二句同樣是一行、同樣是玩笑、同樣不問問題。**但它把話題延伸了。**

## 三、我知道自己容易犯的毛病

（Phase 5 覆盤累積。第一次設定時從三則真實範例看出來的：）

- [x] ⚠️ **對方回了之後只按表情就結束** ← **目前最大的漏洞**
  三則裡有兩則，對方回得很有內容（有情緒、有自我揭露），
  他只按了 ❤️／😆 就沒了。**按表情 = 禮貌收尾 = 對話結束。**
  → 規則：**對方回的訊息只要有情緒或講到自己，一定要再接一句**（一行就好）。
- [ ] 一次講太多（線下強的人常見）—— 目前**沒有**這個問題，三則都很短
- [ ] 太快進入身分 —— 目前**沒有**這個問題
- [ ] 太熱情 —— 目前**沒有**這個問題，溫度抓得剛好
