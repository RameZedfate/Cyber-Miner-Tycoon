# 影片格式：本人照解說片（Photo Explainer）

> 建立於 2026-08-04。這是 `fang__0914` 的**第二種 Reels 格式**，跟原本的「螢幕錄影不出鏡」並行，
> 不是取代。適用於**沒有畫面可錄**的題目（新功能發表、國外還沒開放的工具、觀念說明）。
> 每支 15-60 秒。

---

## 為什麼要有這個格式

原本的公式是「螢幕錄影 ＋ 口白」，前提是**那個工具你打得開**。
但像 Gemini Spark 這種只在美國開放的東西，你根本錄不到畫面。
以前遇到這種題目只能放棄，現在改用：**本人照當主持人 ＋ 字卡與線條圖形**。

順帶解掉 `brand-style.md` 第 147-153 行留下的問題 ——
不出鏡之後「那張臉」這個視覺錨點沒人接手。這個格式把臉放回去了，
但只放在**開場與結尾**，中間仍然是內容，不是講話的人。

---

## ⭐ 成本結論：主線是「零元」，AI 生成是例外

**每天發一支的前提下，AI 生圖／生片養不起。** 實際算過：

| 做法 | 一支成本 | 一天一支的月成本 |
|---|---|---|
| **本文管線（HTML/CSS ＋ ffmpeg）** | **0 credits** | **$0** |
| AI 生圖字卡（`nano_banana_pro` × 8） | 16 credits | 480／月 |
| ＋ AI 動態（`kling3_0_turbo` × 4） | ＋30 credits | 1380／月 → **超過 Plus 方案的 1000，還要再買 $49** |
| AI 說話頭（`seedance_2_0` × 4 段） | 540 credits | 16,200／月 → **完全不可行** |

所以規矩是：

> **字卡、圖形、動態、串接一律走本地免費管線。
> Higgsfield 只留給「真的只有 AI 生得出來」的東西**——例如需要真實感的情境照。
> 而且事前一定先用 `get_cost: true` 問價，不要生了才知道多少錢。

順帶一提，AI 生圖做中文字卡本來就不划算：**中文字會寫錯**，
而 HTML/CSS 的字永遠正確、品牌色永遠精準、改一個字重跑只要 20 秒。

## 骨架（15-60 秒通用）

```
┌─ 0-4 秒 ── 卡 1：本人照 ＋ 痛點大字 ──────────────┐
│  ⚠️ 這 4 秒不准出現工具名，只講痛點              │
├─ 4-8 秒 ── 卡 2：痛點的具體畫面 ─────────────────┤
├─ 8-14 秒 ─ 卡 3：工具名第一次出現 ───────────────┤
├─ 中段 ──── 卡 4-7：它到底做了什麼 ───────────────┤
│  一張卡講一件事，講不完就砍，不要塞               │
├─ 結尾 ──── 卡 8：本人照 ＋ 誠實結論 ＋ Day X／100 ─┤
└──────────────────────────────────────────────────┘
```

| 總長 | 卡數 | 產出時間 | 成本 |
|---|---|---|---|
| 15-20 秒 | 4-5 | ~1 分鐘 | 0 |
| 30-45 秒 | 7-8 | ~3 分鐘 | 0 |
| 45-60 秒 | 9-11 | ~4 分鐘 | 0 |

## 工具

### 1. 產字卡 — `tools/reels-cards/render.py`

```bash
# 第一次用：抓中文字型（約 21MB，不進 git）
bash tools/reels-cards/fetch-fonts.sh

# 產卡
python3 tools/reels-cards/render.py outputs/cards/<題目>/cards.json \
        -o outputs/cards/<題目>
```

用 HTML/CSS 排版 ＋ 內建 Chromium 截圖，輸出 1080×1920 PNG。
**卡片型別：**

| type | 用途 |
|---|---|
| `hook` | 本人照 ＋ 痛點大字（可用 `accent` 指定要標色的詞） |
| `statement` | 純大字 ＋ 線條圖形 |
| `image` | 背景圖（螢幕截圖等）＋ 疊字 |
| `closing` | 本人照 ＋ 結論 ＋ Day X／100 |

**內建圖形（`motif`）** —— 全部 SVG 手畫，不是 AI 生成：

`rows`（帳單列表）｜`rows-circled`（清單圈選）｜`core`（能量核心）
`racks`（機櫃，中間一台亮）｜`phone-locked`（鎖屏手機＋光流）｜`envelope-core`（信封飛向核心）

**斷行自己控**：在 `text` 裡放 `\n`。字級會依最長一行自動回推，
不會出現「電／腦」斷在中間那種狀況。

### 2. 串成影片 — `tools/reels-cards/stitch.py`

```bash
pip install imageio-ffmpeg          # 第一次用
python3 tools/reels-cards/stitch.py outputs/cards/<題目>/cards.json \
        -o outputs/cards/<題目>/video.mp4
```

每張卡可設 `duration`（秒）與 `motion`：
`push` 緩推近｜`pull` 緩拉遠｜`left`／`right` 平移｜`still` 不動。
硬切串接、不加轉場（`brand-style.md`：畫面乾淨，不加花俏轉場）。

> ⚠️ **不要用 `/opt/pw-browsers/ffmpeg-*/ffmpeg-linux`** —— 那是 Playwright 錄螢幕用的精簡版，
> 只有 VP8、沒有 libx264、沒有 zoompan，連 PNG 都讀不進去。用 `pip install imageio-ffmpeg`。

### 3. 口白

`stitch.py` 產的是**無聲**影片。丟進剪映／CapCut 對上自己的口白 ＋ 背景音樂。
（`brand-style.md` 第 144 行：自己的口白信任度比純字卡高很多。）

## 硬規則（違反就不像這個帳號了）

沿用 `brand-style.md`，這裡只列**這個格式特別容易犯**的：

- ❌ **前 4 秒出現工具名** —— 鉤子只講痛點。工具名最早第 8 秒
- ❌ **AI 生成假的辦公室情境圖／假人物** —— `brand-style.md` 第 225 行明令禁止。
  這也是為什麼概念圖用 SVG 線條畫，而不是叫 AI 生一張「有人在辦公室微笑用筆電」
- ❌ **強調色出現兩次以上** —— 黃 `#FFC72C` 一支只准一個地方。
  `render.py` 會擋下來，一支指定兩個 `accent` 會直接報錯
- ❌ **一支講兩件事** —— 講不完拆成兩天
- ✅ **結尾一定要有誠實結論** —— 台灣用不到就說用不到、要付費就說要付費。
  這是支柱 2，也是這個帳號跟其他 AI 帳號最大的差別

## 配色（沿用模板 B，不要重做）

| 角色 | 色碼 |
|---|---|
| 底 | `#0E2A47` 深藍 |
| 主字 | `#FFFFFF` 白 |
| 強調（限一處） | `#FFC72C` 黃 |

字卡一次最多 **12 個中文字**（超過 `render.py` 會警告），粗體置中偏上，
下方保留 **20%** 安全區避開 IG UI。Day 編號固定放**左上角**，只出現在結尾卡。
