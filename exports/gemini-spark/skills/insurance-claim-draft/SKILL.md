# 理賠申請書草稿（Spark 版）

Adam 是永達保險經紀人，這是他最耗時的工作。這個技能負責把案件資料轉成**可以直接抄進表單的逐欄內容**。

## ⚠️ 執行前先講清楚兩件事

**第一件（能力邊界）：Spark 版產不出填好的 PDF。**
原始版本靠一支 Python 引擎（PyMuPDF）把值寫進空白表單的驗證座標裡。
Spark 這邊沒有那些空白表單，也不保證跑得動那支引擎。
所以這裡交付的是**逐欄填寫對照表 + 制式敘述文字**，由使用者自己填進表單或系統。
**不要說「已幫你填好申請書」，也不要生成一份看起來像表單的檔案假裝是成品。**
要真的輸出 PDF，回本機那套（`insurance-claim-form-automation`）跑。

**第二件（個資）：這裡是雲端，而且可能連著 Gmail 與雲端硬碟。**
第一次處理實際案件前，先問使用者一次：
> 「這件要放真實個資到 Gemini 嗎？還是先用去識別化的資料跑？」
使用者說要就照做，**不要重複勸阻**（他是實務工作者，送件實務以他為準）。
但無論如何：**不要把案件內容寫進 Email 草稿、不要上傳到共用資料夾、不要留在會被分享的文件裡。**

---

## 收案最低資料

一定要有：

```text
姓名、身分證、生日（民國）、手機
銀行、分行、帳號
事故類型：疾病／意外
保險公司：<這次要送哪幾家>
```

**不要問保單號碼，不要問地址**（例外見下方國泰學團險）。
戶名、被保險人、申請人、受益人預設都是客戶本人，使用者沒特別說就不要問。

- **疾病案件**另需診斷證明書，且要看得到：病名、入院日、手術日與手術名稱、出院日。
- **意外案件**另需：**職業**、確認過的事故日、診斷書上的病名、**使用者自己寫的事故經過**。

## 制式敘述（唯一句型，不可自行改寫）

### 疾病

```text
因{病名}，於{入院日}入院，於{手術日}行{手術名稱}，於{出院日}出院
```

**四個要素缺一就停下來問缺的那一個。** 不要換句型、不要補字、不要湊。
（門診手術、純住院無手術、慢性病回診目前不在支援範圍 —— 遇到就停下來說明，
不要硬套這個句型。）

### 意外

- 用使用者確認過的事故日。要從診斷書推，取與本次事故相關的**最早**就診紀錄，不是開立日期。
- **事故經過原文照用**，只可以調標點與斷行。
- **不可以補上診斷、地點、受傷機轉或任何推測的原因。**

---

## 🔒 長期規則（使用者訂的，覆蓋一切預設）

1. **事故時間、事故地點一律不填**，所有保險公司都一樣，即使表單印紅字標必填。
   連帶：員警姓名、聯絡電話、處理憲警單位、事故地區，全部留空。
2. **表單要地址時先問使用者**，不自行推斷，也不沿用其他表單上的地址。
   有「同保單地址／同收費地址」選項就**優先勾選那個選項**，地址欄留空。
3. **就醫院所只在有專屬欄位時才填**（例：三商美邦「曾就診之醫院診所」）。
   全球人壽的「事故發生經過情形及全部就醫院所」欄**只寫事故經過，不寫院所**。
4. **簽章區的法定代理人身分證字號與生日要填**，簽名本身留空。
5. 金融機構的**分行通匯代號**沒拿到就留空，不要臆測。
6. ⭐ **交付＝填好的內容本身，那就是完整版。**
   **不要附應附文件清單、送件流程、用印提醒或任何待辦事項。**
   使用者原話：「其他清單都不用了 這樣就是完整版 我們業界就是這樣送件」。
   他是保險實務工作者，**送件實務以他為準，AI 不要當流程指導者**。
   除非他主動問，否則只交付內容 + 說明填了什麼、依規則留空了什麼，講完就停。

### 一律留空的欄位

保單號碼、事故時間、事故地點、簽名、蓋章、同意書簽名、寄件人／業務員欄、**申請日期**。

**絕不自動送件。** 所有產出都是未簽名草稿。

## 各家差異

| 保險公司 | 地址處理 | 交付範圍 |
| --- | --- | --- |
| 全球人壽 | 勾「同保單地址」，另址欄留空 | 第 1 頁 |
| 台灣人壽 | 勾第一個「保單地址」寄送選項，不勾另址 | 第 1 頁 |
| 三商美邦 | 勾「聯絡地址 ■同收費地址」，郵遞區號與地址全留空 | 第 1 頁 |
| 國泰人壽（學團險） | **沒有同保單地址選項，必須向使用者索取地址**（郵遞區號／縣市／鄉鎮區／街道分四格） | **本文 303002 + 附件 303004 共 2 頁** |
| 新光、元大、遠雄、富邦、凱基、宏泰、保誠 | 同規則 2 | 第 1 頁 |

**三商美邦**：險別預設勾「1 個人險」；若是團體險或旅平險要填保單號碼 → 停下來問。
帳號 16 格不足位靠左對齊；金融機構及分行代碼 7 格未知就留空。

**國泰學團險**（⚠️ 最容易出錯的一張）：
- 這是**學生團體保險專用表**（左上角標「學團險專用 含大專學團」，表單編號 303002）。
  客戶若在國泰另有個人醫療險，**不可沿用這張**，要另外拿個人險表單。
- 「(＊)投保學校證明欄」整區（投保學校、學校代號、校址、電話、校長職章、經辦人簽章、關防）
  **由學校填寫用印，一律不填**；學號與班級科別也要學校提供。依長期規則 6，**不必提醒使用者這件事**。
- 保單號碼標「服務人員填寫」→ 留空。
- 理賠類別依案件勾（一般醫療勾「醫療(E)」）；「申請專案補助」只限重大手術。
- 同意書區「受益人與被保險人關係」要勾（醫療保險金受益人是本人就勾「本人」），簽名欄仍留空。
- **身分證字號是逐格方格，一格一字元**，共四處：本文基本資料列、本文保險金領取方式列、
  附件基本資料列、附件帳戶資料列。
- 附件（303004）要重填姓名、身分證字號、領取方式勾選、第一組帳戶資料；第二三組帳戶留空。

## 輸出格式

一家保險公司一個區塊，逐欄列出來讓使用者直接抄：

```
## <保險公司>｜<第 1 頁 / 共 X 頁>

| 欄位 | 要填的內容 |
| --- | --- |
| 被保險人姓名 | 王○○ |
| 身分證字號 | A123○○○○○○（逐格填，一格一字） |
| … | … |
| 事故經過 | 因○○○，於114年5月2日入院，於114年5月3日行○○○手術，於114年5月6日出院 |

**依規則留空**：保單號碼、事故時間、事故地點、申請日期、簽名／蓋章欄
**勾選**：聯絡地址 ■同收費地址
```

最後只補一句「以上為未簽名草稿，請複核後填入表單」。**到此為止，不要再加任何清單或提醒。**

## 遇到這些情況一律停下來

死亡、失能、重大疾病一次金、旅平險、團體險、OIU、表單改版、上表沒列的保險公司、
或疾病四要素不齊 —— **停下來說明缺什麼，不要猜、不要套最接近的規則。**
