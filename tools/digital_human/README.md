# 數字人 Reels 產生器

把 `outputs/scripts/day-XX-*.md` 的腳本，算成一支 1080x1920 的 Reels MP4。
版面規則全部來自 `context/brand-style.md`（深藍模板 B、黃色只准出現一次、
字卡最多 12 字、下方 20% 留給 IG 的 UI）。

## 兩種主播

| 檔案 | 主播 | 什麼時候用 |
|---|---|---|
| `render_real.py` | **你本人**（從影片去背） | 預設。臉是真的，信任度最高 |
| `render.py` | 向量虛擬人 | 不想露臉、或想做成固定的品牌吉祥物時 |

兩支共用同一份時間軸、字卡、背景與版面程式（都定義在 `render.py`）。

## 用法

```bash
# 1. 做主播素材（只要做一次，換照片才要重跑）
python3 tools/digital_human/make_presenter.py --video IMG_4667.mov --at 2.75

# 2. 無聲版，先看節奏對不對
python3 tools/digital_human/render_real.py --day 15

# 3. 配上你的口白，嘴型自動跟著音量跑
python3 tools/digital_human/render_real.py --day 15 --audio voice.wav
```

輸出在 `outputs/videos/day-15-digital-human-real.mp4`。

## 換腳本

時間軸寫在 `render.py` 的 `SEGMENTS`。每一段：

```python
dict(t0=7.0, t1=13.0,
     speak="我錄一支三十秒的影片，平均要重錄十一次",   # 沒有音檔時，用字數推嘴型節奏
     cap=[("重錄 ", WHITE), ("11 次", YELLOW)])        # 字卡，可以分段上色
```

- `cap=None` 就是不出字卡
- `cards=True` 會跑「圖 ＋ 稿 ＋ 聲音」那段動畫
- `flash_badge=True` 會讓右上角的「AI 生成」標變黃

## 關於嘴型

`--audio` 會把你的錄音解成音量包絡，再驅動嘴巴：

- **向量版**（`render.py`）：6 段嘴型切換，看起來像在講話
- **真人版**（`render_real.py`）：下顎微沉的 2D 變形

真人版**不是 AI 唇形同步**，只是幾何變形，所以幅度刻意壓很小。
原本有試過合成口內陰影（張嘴時補一塊暗部 + 牙齒），
但那張照片是閉唇微笑又帶頭部傾斜，疊上去會變成臉上的一塊髒污，
比不動嘴還糟，所以拿掉了。不想要任何嘴部變形就加 `--no-mouth`。

要真正的唇形同步，需要雲端服務（Higgsfield 那類）或本機跑 ML 模型，
目前這個環境的網路政策擋掉了前者。

## 換人 / 換照片要調的東西

`render_real.py` 最上面那幾個座標是**針對這張照片量出來的**，換照片一定要重量：

```python
SRC_HEAD  = (750, 650)    # 原圖裡頭部中心
SRC_MOUTH = (712, 1042)   # 原圖裡嘴巴中心
JAW_TOP   = 1050          # 上唇線
JAW_BOT   = 1210          # 下巴底
```

量法：把去背後的 PNG 貼到深藍底上，畫 50px 格線截圖，直接讀座標。

## 選素材的重點

這次三個素材裡只有一個能用，原因值得記下來：

- ✅ **正面自拍、臉清楚** → 可用
- ❌ 側臉（旅遊照）→ 當不了主播
- ❌ 手機擋住半張臉的鏡子自拍 → 當不了主播
- ⚠️ 背景有路人 → 去背模型會把路人也留下來，要手動切
