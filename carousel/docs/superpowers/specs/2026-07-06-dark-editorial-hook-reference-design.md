# 深色人物雜誌風與開場公式擴充設計

## 目標

將 Adam 提供的三張輪播封面萃取為可重複使用的視覺與文案規則，加入工作區參考庫與 `CODEX.MD`，供後續輪播文案及 Image Two 圖片生成使用。

## 範圍

- 將三張來源圖片保存至 `references/carousel-visuals/`，使用不含作者帳號的描述性檔名。
- 在 `CODEX.MD` 的視覺參考庫新增獨立的「深色人物雜誌風」，涵蓋寫實人物、深色遮罩、白黃高對比字、分隔線、資訊標籤及滑動提示。
- 在爆款鉤子原則新增四種可套用的封面開場公式：工具利益、權威人物、數字清單、反常識資訊缺口。
- 在品質檢查中要求標題承諾由內頁完整兌現，數字、人物說法、日期及產品能力須先查證。

## 邊界

- 不改動既有 YAML 欄位、固定 Markdown 標題、`page_count` 或 5–8 頁輸出契約。
- 不照抄參考圖原文、帳號、品牌識別、收益數字或未查證宣稱。
- 不將參考作者的視覺識別當成 Adam 的固定品牌；只保留通用構圖與資訊層級。
- 不覆蓋工作區現有未提交修改。

## 驗證

- 三張圖片均存在於參考庫，檔案可正常開啟。
- `CODEX.MD` 新增的 Style 與既有 Style 編號、選擇規則一致。
- 四種開場公式包含適用情境、寫法與查證限制。
- `git diff --check` 無內容格式錯誤；既有 LF/CRLF 提示不視為失敗。
