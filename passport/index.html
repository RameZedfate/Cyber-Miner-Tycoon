OWNER LOGIN

持照人登入

登入後可以：更換每張卡片的照片／影片、標記「紀錄已核驗」、匯出更新後的資料。

EDIT MEDIA

設定卡套

貼上照片或影片的網址（.mp4 / .webm / .mov 會自動以影片播放）。也可以放同資料夾檔案，例如 images/tokyo-1.jpg。留空＝清除。

VERIFICATION

出入境紀錄核驗

政府目前沒有開放個人出入境紀錄的自動同步 API。官方作法：向內政部移民署線上申請「入出國日期證明書」（immigration.gov.tw），核對本頁次數相符後，由持照人親自標記「已核驗」。
