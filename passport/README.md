# 護照旅行紀錄 🛂 Passport Travel Log

一頁式 HTML 的「數位護照」：把你每一次出國變成可以蒐集的入境章。
放在 IG 個人簡介連結，讓大家一眼看到你的**護照使用次數**、去過哪些國家、每趟旅程的日期與精選照片／影片。

> 設計成「一本打開的護照」：安全紋紙張底色、入境章收藏牆、機讀區（MRZ）頁尾。
> 中性配色（墨綠／藍墨／紅墨油印），男女都適合；手機優先、單欄輕盈排版，支援深色模式。

## 手機捲動順序

1. **持照人資料頁**：大頭貼 + 名字 + 簡介 + **IG / FB / Threads 圓形圖示**（一鍵到個人檔案）+ 連結
2. **🌍 世界地圖（點選才展開）**：點陣風地圖，去過的國家插國旗（含次數角標）、願望清單灰旗、★HOME
3. **護照使用次數**：大數字動畫 + 國家/城市/海外天數 + 核驗徽章（✓ 已核驗 X/N 趟）
4. **成就勳章「⭕ ⭕ ⭕ 更多」**：最上排展示你挑的勳章（最多 3 枚），其餘收進「更多」展開；
   ⚠️ **勳章只計 ✓ 已核驗的旅程**——沒核驗的旅程照樣記錄，但不會累積成就
5. **入境章收藏牆**：每趟一枚印章，點印章跳到那趟旅程
6. **旅程紀錄［卡片］［卡片］兩欄牆**：最上層是 **📌 釘選區（最多 2 張）**，
   其餘依年份分組；卡片含地點、日期、✓ 核驗勾、團員 TAG、3 格卡套（照片或影片）。
   **點卡片打開「內頁」**看更長的旅行紀錄

## 一鍵登入 / 直接註冊

右上角「登入」會打開登入視窗：

| 方式 | 狀態 | 說明 |
| --- | --- | --- |
| **Google 一鍵登入** | ✅ 可啟用 | 免費申請 OAuth 用戶端 ID 填入 `CONFIG.auth.googleClientId`，用 `ownerEmails` 裡的 Gmail 登入即成為持照人（教學見 CONFIG 註解，3 步驟） |
| **直接註冊** | ✅ 內建 | 「還沒有通行碼？直接註冊」→ 設定暱稱＋通行碼（至少 4 碼）→ 立即登入；帳號存在自己裝置，之後用自己設定的通行碼登入 |
| **通行碼** | ✅ 備用 | `CONFIG.ownerPass`（預設 `2026`，請自行修改） |

> Apple / Instagram 登入已移除：Apple 需要付費開發者帳號，IG 的個人登入 API 已被 Meta 關閉。

> 誠實說明：這是純前端靜態頁，登入的作用是「解鎖編輯介面」。
> 編輯結果只存在自己裝置（localStorage），要公開請按「匯出」把 JSON 貼回 CONFIG 再 push。

## 自訂外觀

- **整頁背景圖**：把照片（例：釜山膠囊列車）放 `images/bg.jpg` 或用網址，填進 `CONFIG.backgroundImage`；
  會自動蓋一層半透明紙紋維持文字可讀（想調濃淡改 CSS 變數 `--veil`）
- **勳章圖案換成 AI 繪圖**：把圖放 `images/`，填進 `CONFIG.achievementArt`，
  例：`{ "first-trip": "images/badge-first.png" }`（勳章代號見 CONFIG 註解）
- **展示哪幾枚勳章**：改 `CONFIG.featuredBadges`（最多 3 枚），或登入後在「更多」清單按「📌 展示」
- **釘選卡片**：trips 加 `pinned:true`（最多 2 張），或登入後按卡片上的 📌

## 登入後可以做什麼

- **＋新增**：直接在頁面新增旅程卡片（選國家自動帶國旗/地圖座標/洲別），次數、印章、地圖、成就全部即時更新
- **懶人匯入**：把移民署「入出國日期證明書」的文字整段貼上 → 自動兩兩配對「出國→回國」
  生成卡片並打勾 ✓ 已核驗（支援西元與民國年）。目的地之後點卡片再補
- **點卡片 → 內頁**：寫更長的旅行紀錄（訪客也看得到內文，只有你能編輯）
- **✎ 換卡套**：每格可貼照片或影片網址（`.mp4/.webm/.mov` 自動當影片）
- **編輯資料／刪除**：內頁裡的「編輯資料」可改日期地點、勾選 ✓ 已核驗；頁面新增的卡片可刪除
- **匯出**：把所有編輯打包成 JSON 複製到剪貼簿，貼回 `index.html` 的 `CONFIG.trips` 即公開

## 關於「外交部驗證」

政府（外交部／移民署）**沒有開放**個人出入境紀錄 API，無法自動同步。本頁採「官方文件＋本人打勾」：

1. 向移民署線上申請「**入出國日期證明書**」（immigration.gov.tw）
2. 有證明書 → 卡片打勾 ✓（或用懶人匯入直接生成已打勾卡片）
3. 沒有證明書 → 不打勾，**照樣可以記錄與統計**，只是不顯示 ✓

## 怎麼改成自己的資料

打開 `index.html` 最上方 `✏️ CONFIG`（有中文註解）：`auth`（登入）、`profile`、`home`、`crew`（團員名冊）、
`wishlist`、`trips`（每趟含 `verified`、`journal` 內頁、`photos` 卡套、`crew` TAG）。
新國家補 `COUNTRY_COORDS`（地圖座標）與 `COUNTRY_META`（中文名→國旗）各一行即可。

> 目前檔案裡是**示範資料**，記得換成自己的紀錄。

## 上線（放到 IG 簡介）

1. repo → Settings → Pages 開啟 GitHub Pages
2. 網址：`https://你的帳號.github.io/Cyber-Miner-Tycoon/passport/`
3. 出國回來 → 手機登入直接新增卡片/換照片 → 有空時按「匯出」貼回 CONFIG → push 公開

## 隱私提醒

- 只放願意公開的資訊；護照號碼、真實英文全名、出生日期**不要**放上去
- 機讀區（頁尾 `P<TWN...`）是裝飾用統計，不是真的護照機讀碼
- TAG 團員前先問過本人
