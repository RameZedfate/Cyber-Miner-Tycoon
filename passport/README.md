# 護照旅行紀錄 🛂 Passport Travel Log

一頁式 HTML 的「數位護照」：把你每一次出國變成可以蒐集的入境章。
放在 IG 個人簡介連結，讓大家一眼看到你的**護照使用次數**、去過哪些國家、每趟旅程的日期與精選照片。

> 設計成「一本打開的護照」：安全紋紙張底色、入境章收藏牆、機讀區（MRZ）頁尾。
> 中性配色（墨綠／藍墨／紅墨油印），男女都適合；手機優先、單欄輕盈排版，支援深色模式。

## 手機捲動順序（照需求設計）

1. **持照人資料頁**：大頭貼 + 名字 + 簡介 + 連結（像護照的資料頁，含國籍/首航/最近出國）
2. **護照使用次數**：超大數字滾動動畫 + 國家/城市/海外天數統計
3. **入境章收藏牆**：每趟旅程一枚印章（蓋章進場動畫），點印章直接跳到那趟旅程；
   還沒去的夢想清單顯示成「未解鎖」虛線格 → 蒐集癖發作
4. **旅程紀錄**：依年份分組的卡片，每張含地點、日期、天數、一句話、**最多 3 張精選照片**（可點開放大）

## 這個資料夾有什麼

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 主程式（資料 + 版面 + 動畫全在這一檔） |
| `images/` | （自行建立）放你的照片，例如 `images/tokyo-1.jpg` |
| `README.md` | 本說明 |

## 怎麼改成自己的資料

打開 `index.html`，找到最上方 `✏️ CONFIG` 區（有中文註解），只要改這一區：

- **profile**：名字、IG 帳號、簡介、大頭貼（`avatar` 放網址或 `images/me.jpg`，留空顯示姓名首字）、連結按鈕
- **wishlist**：還想去的國家（顯示成未解鎖印章）
- **trips**：每趟旅程一筆
  - `start` / `end`：日期 `YYYY-MM-DD`，天數自動計算
  - `photos`：最多 3 張。放網址或 `images/xxx.jpg`；留空 `""` 會顯示虛線佔位框等你補
  - `ink`：印章墨色 `"green" / "blue" / "red"`，留空自動輪流
  - 次數、國家數、城市數、天數、洲別統計、機讀區數字**全部自動算**，不用手動改

> 目前檔案裡是**示範資料**，記得換成自己的紀錄。

## 上線（放到 IG 簡介）

1. 推上 GitHub 後，repo → Settings → Pages 開啟 GitHub Pages（同 cheap-flights 的做法）
2. 網址會是 `https://你的帳號.github.io/Cyber-Miner-Tycoon/passport/`
3. 把網址放進 IG 個人簡介即可；日後出國回來，改 `CONFIG` 的 `trips` 再 push，頁面就自動更新

## 隱私提醒

- 頁面上只放你願意公開的資訊；護照號碼、真實英文全名、出生日期**不要**放上去
- 機讀區（頁尾那兩行 `P<TWN...`）是裝飾用的統計數字，不是真的護照機讀碼
