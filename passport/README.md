# 護照旅行紀錄 🛂 Passport Travel Log

一頁式 HTML 的「數位護照」：把你每一次出國變成可以蒐集的入境章。
放在 IG 個人簡介連結，讓大家一眼看到你的**護照使用次數**、去過哪些國家、每趟旅程的日期與精選照片／影片。

> 設計成「一本打開的護照」：安全紋紙張底色、入境章收藏牆、機讀區（MRZ）頁尾。
> 中性配色（墨綠／藍墨／紅墨油印），男女都適合；手機優先、單欄輕盈排版，支援深色模式。

## 手機捲動順序

1. **持照人資料頁**：大頭貼 + 名字 + 簡介 + 連結（含國籍/首航/最近出國）
2. **🌍 世界地圖（點選才展開）**：點陣風世界地圖，去過的國家插上國旗（去 2 次以上有次數角標）、
   願望清單是灰旗、出發地是 ★HOME，點旗子會顯示國家與次數
3. **護照使用次數**：超大數字滾動動畫 + 國家/城市/海外天數統計 + **紀錄核驗徽章**
4. **成就勳章**：唯一／稀有／一般三種等級，未解鎖的顯示進度條（例：蓋章 ×10 → 9/10）
5. **入境章收藏牆**：每趟旅程一枚印章（蓋章動畫），點印章跳到那趟旅程；未去的顯示「未解鎖」
6. **旅程紀錄**：依年份分組的卡片，含地點、日期、天數、一句話、**同行團員 TAG**、
   **最多 3 格卡套（照片或影片都可以）**，點了可放大播放

## 登入與編輯（LOGIN）

- 右上角「登入」→ 輸入通行碼（`CONFIG.ownerPass`，預設 `2026`，**請自行修改**）
- 登入後：
  - 每格卡套出現 ✎ 按鈕（空格直接點）→ 貼上照片或影片網址（`.mp4/.webm/.mov` 自動當影片）
  - 護照使用次數下方的核驗徽章可以標記「已核驗」＋核驗年月
  - 下方工具列有「**匯出資料**」：把你在頁面上做的編輯打包成 JSON 複製到剪貼簿

### ⚠️ 誠實說明：編輯的儲存範圍

這是純前端靜態頁（GitHub Pages），**沒有後端資料庫**：

- 登入後的編輯只存在**你自己這台裝置**（localStorage），別人打開網頁看不到
- 要讓大家看到 → 按「匯出資料」→ 把 JSON 貼回 `index.html` 的 `CONFIG` → push 上 GitHub
- 通行碼是輕量前端鎖（防誤觸，不是資安等級的保護），反正編輯本來就只影響自己裝置

## 關於「外交部驗證」

政府（外交部／內政部移民署）**沒有開放**個人出入境紀錄的自動同步 API，
所以「上傳後自動跟外交部核對」目前技術上做不到，也不建議任何要你輸入政府帳密的做法。

**官方可行流程**：向移民署線上申請「**入出國日期證明書**」（immigration.gov.tw）→
自己核對次數相符 → 登入本頁標記「✓ 已核驗」＋年月。徽章代表「持照人已自我核驗」。

## 怎麼改成自己的資料

打開 `index.html`，找到最上方 `✏️ CONFIG` 區（有中文註解）：

- **ownerPass**：登入通行碼（記得改）
- **profile**：名字、IG、簡介、大頭貼、連結按鈕
- **home**：出發地（地圖上的 ★）
- **crew**：團員名冊（名字 + IG 網址），旅程用 `crew:["kai"]` 引用
- **wishlist**：還想去的國家（未解鎖印章 + 地圖灰旗），`code` 要對得上 `COUNTRY_COORDS`
- **trips**：每趟旅程一筆；`photos` 每格可放照片網址、影片網址或 `images/xxx.jpg`
- 新國家若地圖沒座標，在 `COUNTRY_COORDS` 補一行 `代碼:[經度,緯度]` 即可
- 次數、國家數、天數、成就、地圖插旗、機讀區**全部自動計算**

## 上線（放到 IG 簡介）

1. repo → Settings → Pages 開啟 GitHub Pages（同 cheap-flights 的做法）
2. 網址：`https://你的帳號.github.io/Cyber-Miner-Tycoon/passport/`
3. 出國回來 → 手機登入頁面換照片 → 電腦按「匯出資料」貼回 CONFIG → push 更新

## 隱私提醒

- 只放願意公開的資訊；護照號碼、真實英文全名、出生日期**不要**放上去
- 機讀區（頁尾 `P<TWN...`）是裝飾用統計，不是真的護照機讀碼
- TAG 團員前先問過本人
