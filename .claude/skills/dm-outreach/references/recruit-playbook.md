# 增員線手冊（Recruit Playbook）

> 增員（招募新夥伴）跟開發客戶**不是同一件事**，用同一套話術會兩邊都做不好。
> 寫增員草稿前讀這份；共通的寫作規則仍然適用 [reply-playbook.md](reply-playbook.md)。

---

## 1. 根本差異

|  | 客戶線 | 增員線 |
|---|---|---|
| 你在找什麼 | **風險缺口** | **現況不滿 ＋ 有改變的可能** |
| 觸發點 | 生活變動（結婚、生子、買房、家人生病） | 工作不滿、時間不自由、收入天花板、想被看見、剛離職／想離職 |
| 對方的防禦點 | 「又要賣我東西」 | 「又要拉我做直銷」 |
| 決策時間 | 週～月 | **月～年**（換工作是人生決定） |
| 搞砸的成本 | 少一個客戶 | **少一個朋友**（增員對象常是同溫層） |
| 節奏 | 正常 | **比客戶線慢一倍** |

> 🔑 最關鍵的一條：**增員對象通常是你認識的人。** 客戶談壞了關係還在，增員談壞了會很尷尬。
> 所以增員線的每一步都要留退路 —— 讓對方可以「不接話」而不用拒絕你。

## 2. 紅線（草稿裡絕對不准出現）

| 禁止 | 為什麼 |
|---|---|
| 月入 X 萬、年收 X 百萬、保證收入、底薪保障（具體數字） | 招募不實廣告的風險，而且對方會拿去驗證 |
| 輕鬆賺、躺著領、被動收入、財富自由、時間自由到爆 | 這是直銷語言，講出來對方立刻歸類 |
| 「你這麼厲害不做業務可惜了」 | 空洞的恭維，一聽就是話術 |
| 「跟我一起打拼」「加入我們團隊」 | 第 1-3 階講這個等於直接邀約，太早 |
| 貶低對方現在的工作 | 「你那份工作沒前途」→ 關係直接結束 |
| 拿別人的收入截圖／團隊獎金表 | 招募文宣，屬公司管控範圍 |

**改成什麼：** 講**你自己的具體工作內容與改變**，不講對方應該怎樣。
- ❌「這行收入天花板很高」
- ✅「我這兩個月把整理文件那塊丟給 AI 做，一週省下大概 5 小時」

事實描述 vs 承諾，差別就在這裡。事實可以講，承諾不能講。

## 3. 四階段（增員版）

| 階段 | 任務 | 訊號 |
|---|---|---|
| 1 **破冰** | 同客戶線 | 他回你 |
| 2 **聽現況** | 讓他講工作，你完全不評論 | 他開始抱怨或講細節 |
| 3 **不滿浮現** | 他自己講出「想換」「累」「沒成就感」「卡住」 | **他自己說的**，你不能替他總結 |
| 4 **開一扇門** | 不是邀約，是「讓他問你」 | 他問「那你現在都在做什麼？」 |

### 第 4 階的核心技巧：不要邀請，要讓他問

增員最有效的一句話不是「你要不要來做保險」，而是讓對方**主動問你在做什麼**。

做法是**講你自己**，講到有意思，然後停住：

> 「我最近在弄一個東西，把我工作上最煩的文書處理丟給 AI 做，
> 現在填一份表的時間從半小時變五分鐘」
>
> ——（停。不要接「你要不要也來試試」）

如果對方有一點點不滿現況，他會接：「這什麼？」「你在做什麼工作啊？」
**這一問，主客關係就換了。** 他問，你答，你就不是在推銷。

如果他沒接 —— 那就是他現在沒有動機，記進追蹤表，三個月後再說。**不要補一句去推。**

## 4. Adam 的天然增員素材（這是最大優勢，一定要用）

大部分保險增員的困境是：**你能講的只有「這行很好」，聽起來就是話術。**

Adam 不一樣，他手上有一個看得見、摸得到、每天更新的東西 —— **IG 的「AI 挑戰 100 天」連載**。

這對增員的意義：

| 一般增員的形象 | Adam 可以呈現的形象 |
|---|---|
| 要出賣人情、拉親友 | 有系統、有工具、在做內容 |
| 靠話術、靠勤跑 | 用 AI 把繁瑣的部分做掉 |
| 講不出具體在做什麼 | **每天一支影片就是證據** |
| 「來聽說明會」 | 「你可以先看我在幹嘛」 |

**操作方式：** 增員對象不需要冷開場，直接讓他看 IG。
> 「我最近在做一個一百天的挑戰，每天記錄我用 AI 解掉一件工作上的麻煩事，
> 你可能會有興趣」

這句話的厲害之處：**它完全沒有提到保險，也沒有提到增員**，但對方看完 20 支影片之後，
他會知道你在做什麼工作、你怎麼做事、你是什麼樣的人。等他問你的時候，前面三階已經自動走完了。

> ⚠️ 反過來的風險：如果 IG 上有任何「炫耀收入／招募文宣」，這個優勢會立刻失效，
> 而且會退化成一般的直銷觀感。`brand-style.md` 的方向（誠實、講失敗、不推銷）
> **本身就是最好的增員資產**，不要為了增員去改。

## 5. 增員對象的分類（記進追蹤表，代號 `R-0XX`）

| 訊號 | 意義 | 動作 |
|---|---|---|
| 抱怨工作但沒說要換 | 大多數人的常態，**不是增員訊號** | 記著，不動作 |
| 說「好想離職」但已經說一年了 | 情緒性，不是決定 | 觀察，別投入 |
| **剛離職／剛被資遣／公司有變動** | ⭐ 最強訊號，但**要先關心人，不要談機會** | 先陪，兩週後再說 |
| 主動問你在做什麼／怎麼做的 | ⭐ 進第 4 階 | 48 小時內接手 |
| 現在收入不錯但抱怨時間 | 好對象（保險換的是時間結構） | 慢慢養，講你的時間怎麼安排 |
| 現在收入低且不穩 | ⚠️ 要小心 —— 對方可能撐不過前期 | 誠實講前期的難處，不要美化 |

> **最後一條要特別強調：** 增員時誠實講前期的辛苦，短期會流失一些人，
> 長期會留下能留下的人。美化招來的人三個月就走，而且會反過來影響你的口碑。
> 這跟 `brand-style.md` 裡「誠實說失敗最建立信任」是同一個原則。

## 6. 增員線的常見情境

| 情境 | 處理 |
|---|---|
| 對方問「做保險是不是要一直拉朋友」 | ⭐ **最好的問題**。誠實回答，並用你的 IG 當反例：「我現在的做法是先做內容，讓人來問我」 |
| 對方問「賺得到錢嗎」 | 不給數字（紅線）。「這個要看你怎麼做，講數字沒意義，我可以跟你講我實際的一天長怎樣」 |
| 對方說「我不適合做業務」 | 不要反駁。「其實我也不覺得每個人都適合」← 認同會讓他自己開始想 |
| 對方明確拒絕 | 收得漂亮：「沒事啦，本來就只是想到你，隨口講一下」← 留住關係最重要 |
| 對方現在是你的客戶 | ⚠️ 特別小心。增員失敗可能連客戶都失去。**確定訊號很強才開口** |
| 對方是同業（想挖角） | ⚠️ 涉及同業競業與職業道德，**這個技能不寫這種草稿**，請自行判斷 |

## 7. 增員的自我檢查（送出前）

1. 這則有沒有出現收入數字或「輕鬆」類的字？
2. 我是在講**我自己在做什麼**，還是在講**他應該怎樣**？（後者一律重寫）
3. 這則講完，對方可以不接話就自然結束嗎？（不行 → 太重）
4. 觸發點是**他自己講的**，還是我推論的？（我推論的 → 還沒到第 3 階）
5. 如果他明天拒絕我，我們的關係還在嗎？（不在 → 這則不要送）
